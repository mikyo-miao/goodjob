暴雨倾盆。圣克图斯神圣帝国边境，黑森林驿站外一夜无月。钱袋砸进泥水，溅起一朵浑浊的泥花——那是你三年的遣散费。

「晨星家只有一条规矩：让主将在阵前倒下的人，不能再留在阵里。」——奥蕾莉亚

她们不知道，三年里每一次术式失控，都是你用一根看不见的灰线替她们拨正的。今夜借着她们的傲慢，你主动斩断了与那五个人的同源共生锁。

雨声忽然变得很慢、很远。意识深处，一个霜白短发的女孩盘腿坐在灰烬里，歪头看你——
