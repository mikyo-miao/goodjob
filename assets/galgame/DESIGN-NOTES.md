# 死装同桌 · 周清禾 — 引导页设计记录

## 方向（Unslop 五行）

- **产品**：角色卡《死装同桌 · 周清禾》的视觉小说级设定集与开局契约生成页，面向喜欢青春校园纯爱拉扯的玩家。
- **性格**：通透、嘴硬、书卷气。初春午后教室的明亮空气感，少女极力维持体面的克制秩序，耳根先红的微妙破绽。
- **世界**：致远楼四楼靠窗倒数第二排。暖奶油硬卡纸、水磨石走廊的浅薄荷天光、0.38mm 蓝黑墨水、淡樱粉耳尖、老张的朱砂红粉笔。
- **Moment**：① 第三幕 WebGL 呼吸立绘 + 七处视线落点 + 十六套衣橱；② 第四幕 1:1 卡内状态栏实时试玩沙盒。
- **签名**：涂改带白线与 0.5cm 手画方格线。用于章节分割、卡片底纹与画框衬底，替代星芒、发光球和无意义装饰。

## 当前实现

单页长卷，`body` 不再锁定全屏。页面结构：

```
开屏黑板（真实素材进度 101 → 100）
常驻顶栏（章节锚点 / 距高考 / 深夜电台 / 直达选座）
01 三八线（教室取景框 + 三张议论纸条 + ADV 对白）
02 来处（记忆主画幅 + 六张胶片分镜）
03 隔桌（观察记录 + WebGL 立绘 + 视线落点 + 衣橱）
03.5 同桌手记（学籍 / 桌角旧物 / 日常口吻 / 七张物证）
04 百日（四条日常线 + 七处走读地图）
04.5 实机沙盒（同桌行动试玩 + 卡内状态栏）
05 落座（七张来路身份卡 + 学籍表单 + 目标卡 + 红手印）
```

### 样式

- `assets/css/tokens.css`：唯一 Design Tokens。暖象牙底、蓝黑墨水字、樱花暗粉主强调、朱砂印泥红仅用于倒计时与手印。
- `assets/css/layout.css`：骨架、开屏黑板、顶栏、章节、取景画框、按钮、弹窗、页脚、响应式。
- `assets/css/sections.css`：七个区块的组件与移动端重排。
- `assets/css/statusbar-sandbox.css`：`.qh-sandbox` 作用域内的状态栏预览，含白昼 / 深夜双皮肤与容器查询。

### 脚本

- `assets/js/data.js`：全部文案与数据（对白、记忆、衣橱、视线落点、手记、玩法、身份、随机行囊、原卡开场白）。
- `assets/js/live2d.js`：WebGL 网格蒙皮立绘引擎，未改动。
- `assets/js/app.js`：开屏、对白、记忆、立绘、衣橱、手记、玩法、沙盒、契约、弹窗、键盘与滚动联动。

### 旧文件

`shell.css`、`act-a.css` ~ `act-e.css`、`extras.css`、`beautify.css`、`card-theme.css`、`opening.js` 不再被 `index.html` 引用，保留作历史参考。新页面只加载上述四个 CSS 与三个 JS。

## 文案规则

- 不出现“死装、大女主、人设、破防、机制、大事件、触发、解锁”等元标签。
- 内心独白一律第一人称短句，像 18 岁嘴硬女孩脑子里闪过的念头，不替读者总结心理。
- 不替玩家说话或行动；开场文稿明确要求从“她把水笔推过三八线”之后接着写。
- 数字统一用等宽数字；金额、粉丝、学力、好感不写“系统提示”口吻。
- 身体描写优先写动作、呼吸、耳根、指尖与器物，不写商品价签式标签。
- 视觉小说式对白用中文引号；按钮与短标签不带句号。

## 交互与验收

- 开屏进度由真实图片与首屏视频加载计数驱动，最短展示 850ms，6 秒兜底；点击按钮或向下滚动揭幕。
- 顶栏用滚动位置更新当前章节；锚点平滑滚动；`scroll-padding-top` 避开固定顶栏。
- 立绘用 `IntersectionObserver` 延迟初始化；WebGL 不可用时替换为静态立绘，点击仍按最近锚点判定部位。
- 视频按区块延迟加载；无视频的地点只显示海报；加载失败保留海报。
- 沙盒明确标注“预览数据”，不冒充宿主实时状态；行动按钮只生效一次，可重置。
- 契约文稿使用 `navigator.clipboard`，失败回退 `execCommand('copy')`；弹窗内可再次复制。
- 键盘：第一幕空格 / 回车 / 左右方向键；弹窗 Esc 关闭与焦点循环；所有按钮有 `:focus-visible`。
- `prefers-reduced-motion` 下关闭打字机、浮尘与大部分过渡。
- Lighthouse（912×670，桌面）：Accessibility 1.0、Best Practices 1.0、SEO 1.0。
- 已检查视口：912×670 桌面、390×670 移动 iframe；无横向溢出。
- 已验证：对白推进、议论纸条、记忆切换、视线落点、衣橱解锁、手记分页、物证弹窗、玩法切换、沙盒三行动与昼夜、身份选择、随机行囊、按印、生成与复制、原卡开场白弹窗、深夜电台开关。

## 如何改文案

1. 第一幕对白：`assets/js/data.js` 的 `act1`，字段 `mode / guard / guardText / line / inner`。
2. 同学议论：`gossip`，字段 `who / quote / inner`。
3. 六段记忆：`memories`，字段 `short / title / caption / video / poster`。
4. 十六套衣橱：`outfits`，字段 `line / inner / note / locked / private`。
5. 七处视线落点：`hotspots`，每处三段 `emo / heat / line / inner / note / mask`。
6. 手记：`archive.grid`、`archive.scraps`、`voices`、`polaroidLabels`。
7. 四条玩法与地图：`plays`、`mapScenes`。
8. 七种身份与随机行囊：`identities`、`presets`。
9. 沙盒初始值、行动结果与便签：`assets/js/app.js` 的 `sbFresh()` 与 `sandboxAction()`。

改完文案后，同步更新 `index.html` 中 CSS / JS 的 `?v=` 版本号，避免浏览器缓存旧文件。
