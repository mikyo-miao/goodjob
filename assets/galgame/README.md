- **第一人称机关**：第一幕课桌三动作、第三幕双面牛皮纸笔记本翻面、常驻耳机播放器与 23:45 微信语音撤回、第五幕朱砂印泥按手印。

  - `tools/gen_nai_assets.py`：NAI V5 + `V5偏live2D精致动漫` 画风串，生成 7 张身份卡、4 张透明底道具、8 张场景。
  - `tools/gen_music_ace.py`：本机 ComfyUI ACE-Step 1.5 Turbo 生成 `assets/audio/bgm_desk.mp3`、`bgm_origin.mp3`、`bgm_night.mp3`。
  - `tools/gen_h3_videos.py`：本机 ComfyUI MiniMax H3 以新场景图为首帧生成 C0 / B6 / D2 / D5 循环视频，并抽取环境音。
